# 屏幕鼠标控制插件 (Screen Mouse Controller)

OBS Studio插件，用于读取屏幕内容、追踪目标并控制鼠标。增强版支持多种图像识别算法、颜色追踪、边缘检测、暴力模式、吸附功能以及鼠标轨迹平滑控制。

## 功能特性

### 图像识别增强
- **多种模板匹配算法**：支持TM_CCOEFF_NORMED、TM_CCORR_NORMED、TM_SQDIFF、TM_SQDIFF_NORMED四种算法
- **颜色识别与追踪**：基于HSV颜色空间的颜色检测与追踪
- **边缘检测**：Canny边缘检测算法
- **游戏人物追踪**：头部/胸口可选追踪

### 鼠标控制增强
- **轨迹平滑化**：减少鼠标移动抖动
- **速度控制**：可调节的鼠标移动速度
- **按键模拟**：支持左键、右键点击
- **滚轮控制**：上下滚动
- **按键模拟**：按键按下、释放

### 性能优化
- **多线程架构**：独立的捕获线程和处理线程
- **帧队列**：使用deque缓冲最近5帧
- **低延迟设置**：最小10ms捕获间隔
- **线程锁保护**：线程安全的数据访问
- **暴力模式**：极限性能配置，一键启用所有最高性能设置

### 暴力模式
- **一键极限性能**：自动设置所有参数为极限值
- **10ms捕获间隔**：最高频率屏幕捕获
- **0.5匹配阈值**：最宽松的匹配标准
- **全追踪开启**：颜色追踪+边缘检测同时启用
- **2.0x移动速度**：最快鼠标移动速度
- **双重警告确认**：确保用户知晓风险

### 吸附功能
- **网格吸附**：对齐到隐形网格线
- **边缘吸附**：对齐到素材边界
- **中心吸附**：对齐到画布中心
- **元素吸附**：配合屏幕检测，吸附到类似素材内容
- **可调节阈值**：灵活控制吸附灵敏度

### 自动追踪
- **插件加载自动开始**：设置后加载插件即开始追踪
- **自动加载模板**：设置后自动加载预设模板图片

## 安装步骤

### 1. 安装Python依赖

```bash
pip install -r requirements.txt
```

或者使用提供的安装脚本：
```bash
install.bat
```

### 2. 安装插件

1. 打开OBS Studio
2. 进入 `工具` -> `脚本`
3. 点击 `+` 号，添加 `screen-mouse-controller.py` 文件
4. 脚本会自动加载

## 使用方法

### 快速开始

1. **启用屏幕捕获**：勾选"启用屏幕捕获"
2. **设置捕获间隔**：建议设置为50ms以获得流畅追踪
3. **启用目标追踪**：勾选"启用目标追踪"
4. **加载模板**：点击"设置当前屏幕为模板"或选择模板图片路径
5. **启用鼠标控制**：勾选"启用鼠标控制"

### 追踪设置

- **追踪目标**：选择"头部"或"胸口"
- **匹配算法**：根据场景选择合适的算法
  - TM_CCOEFF_NORMED：默认推荐，通用性好
  - TM_CCORR_NORMED：速度快但精度稍低
  - TM_SQDIFF：适用于查找最小差异
  - TM_SQDIFF_NORMED：标准化版本
- **匹配阈值**：建议0.7-0.9

### 暴力模式

1. 在"暴力模式"选项卡中勾选"启用暴力模式（最高性能）"
2. 仔细阅读警告信息
3. 勾选"确认启用暴力模式（风险自负）"
4. 系统自动应用极限参数：
   - 捕获间隔：10ms
   - 匹配阈值：0.5
   - 颜色追踪：开启
   - 边缘检测：开启
   - 轨迹平滑：关闭
   - 移动速度：2.0x

### 吸附功能

#### 基础吸附
1. 在"吸附功能"选项卡中勾选"启用吸附功能"
2. 选择需要的吸附类型：
   - **网格吸附**：对齐到网格线
   - **边缘吸附**：对齐到素材边界
   - **中心吸附**：对齐到画布中心
3. 调整网格大小和吸附阈值
4. 设置画布尺寸
5. 点击"测试吸附"验证设置

#### 元素吸附（配合屏幕检测）
1. 启用屏幕捕获和目标追踪
2. 加载模板图片
3. 在吸附设置中展开"元素吸附（配合屏幕检测）"
4. 勾选"启用元素吸附"
5. 调整元素灵敏度（0.3-1.0）
6. 系统会自动检测屏幕中的边缘、颜色区域和类似模板的元素
7. 鼠标会吸附到最近的检测元素位置

### 颜色追踪

1. 启用颜色追踪
2. 调整HSV颜色范围：
   - H (色相)：0-180
   - S (饱和度)：0-255
   - V (明度)：0-255
3. 可使用颜色选择器工具获取目标颜色值

### 边缘检测

1. 启用边缘检测
2. 调整阈值：
   - 阈值1：建议50-100
   - 阈值2：建议100-200
3. 较低的阈值会产生更多边缘

### 鼠标控制设置

- **启用轨迹平滑**：使鼠标移动更平滑
- **平滑系数**：0.1-1.0，值越小越平滑
- **启用速度控制**：限制鼠标移动速度
- **移动速度**：0.1-2.0倍速

### 操作按钮

- **设置当前屏幕为模板**：将当前屏幕作为追踪模板
- **移动鼠标到目标**：立即将鼠标移动到设定的目标坐标
- **执行左键点击**：模拟左键点击
- **执行右键点击**：模拟右键点击
- **测试吸附**：测试吸附配置

## 算法对比

### 模板匹配算法

| 算法 | 速度 | 精度 | 适用场景 |
|------|------|------|----------|
| TM_CCOEFF_NORMED | 中 | 高 | 通用，推荐首选 |
| TM_CCORR_NORMED | 快 | 中 | 快速扫描 |
| TM_SQDIFF | 快 | 中 | 查找最小差异 |
| TM_SQDIFF_NORMED | 中 | 高 | 标准化查找 |

### 性能建议

- **普通模式**：捕获间隔50ms，阈值0.8
- **暴力模式**：捕获间隔10ms，阈值0.5，所有追踪开启
- **颜色追踪**：确保目标颜色与背景对比明显
- **边缘检测**：适用于轮廓明显的物体
- **元素吸附**：配合追踪功能，自动吸附到检测到的元素

## 追踪技巧

1. **模板选择**：
   - 选择颜色鲜明、特征明显的区域
   - 模板大小建议100x100到300x300像素
   - 确保模板在场景中相对稳定

2. **算法选择**：
   - 通用场景：TM_CCOEFF_NORMED
   - 性能不足：TM_CCORR_NORMED
   - 精确匹配：TM_SQDIFF_NORMED

3. **暴力模式**：
   - 适用于快速移动的场景
   - 性能不足时慎用
   - 建议配合元素吸附使用

4. **参数调整**：
   - 追踪不到目标：降低阈值或开启暴力模式
   - 错误追踪：提高阈值或使用更精确的模板
   - 鼠标抖动：启用轨迹平滑，降低速度

5. **吸附技巧**：
   - 元素吸附需要配合追踪功能使用
   - 灵敏度越高，越容易匹配元素
   - 建议与模板匹配配合，效果最佳

## 性能优化技巧

1. **暴力模式**：性能充足时使用，一键极限优化
2. **降低捕获间隔**：性能不足时增加到100-200ms
3. **选择合适算法**：TM_CCORR_NORMED最快
4. **禁用不需要的功能**：关闭边缘检测和颜色追踪可提升性能
5. **减小模板大小**：过大的模板会降低匹配速度
6. **合理使用吸附**：启用太多吸附模式会影响性能

## 注意事项

- 首次使用需要安装Python依赖包
- 确保OBS Studio已安装Python脚本支持
- 使用鼠标控制功能时注意不要影响其他操作
- 暴力模式会占用大量系统资源，谨慎使用
- 元素吸附需要启用屏幕捕获和追踪功能
- 建议在全屏游戏模式下使用，获得最佳追踪效果
- 颜色追踪需要目标颜色与背景有足够对比度

## 技术架构

### 多线程设计

```
主线程 (OBS)
    ↓
捕获线程 ──> 帧队列(deque) ──> 处理线程
    ↓                              ↓
屏幕截图                      图像处理
    ↓                              ↓
PyAutoGUI                    模板匹配/颜色检测/边缘检测
    ↓                              ↓
鼠标控制 <──────────────────── 结果输出
    ↓
吸附处理 ──> 元素检测 ──> 最终坐标
```

### 核心组件

- **MouseController**：鼠标控制类，负责轨迹平滑和按键模拟
- **ImageProcessor**：图像处理类，负责模板匹配、颜色追踪、边缘检测
- **SnapController**：吸附控制类，负责网格/边缘/中心/元素吸附
- **frame_queue**：帧缓冲队列，缓存最近5帧
- **processing_lock**：线程锁，保护共享数据

### 吸附系统工作流程

```
追踪目标坐标 → 检测屏幕元素(边缘/颜色/模板)
     ↓
计算最近元素 → 应用吸附规则
     ↓
网格吸附 → 边缘吸附 → 中心吸附 → 元素吸附
     ↓
最终坐标 → 鼠标移动
```
